# ✈️ TravelConnect

> A lightweight web platform that helps travelers **discover and connect with travel agents** — and reach them directly via email.

---

## 🌍 Overview

TravelConnect bridges the gap between travelers and professional travel agents. Browse agents, explore their specialties, and get in touch instantly — no sign-up required.

---

## ✨ Features

- 🧭 **Browse Travel Agents** — Discover agents by specialty or destination
- 📧 **Email Integration** — Contact agents directly from the platform
- ⚡ **Fast & Lightweight** — Built with zero frameworks, pure vanilla JS
- 📱 **Responsive Design** — Works seamlessly on desktop and mobile

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Markup & structure |
| CSS3 | Styling & responsive layout |
| Vanilla JavaScript | Interactivity & email functionality |

---

## 🚀 Getting Started

No build tools or dependencies required!

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/travel-connect.git
   cd travel-connect
   ```

2. **Open in your browser**
   ```bash
   # Simply open the index.html file
   open index.html
   ```
   Or drag and drop `index.html` into your browser.

## 📧 Email Feature

Agents can be contacted directly using the built-in email form, powered by the [`mailto`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/a#href) protocol or a third-party service like [EmailJS](https://www.emailjs.com/) — no backend needed.
